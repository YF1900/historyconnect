# ヒストリーコネクト（歴史探究アプリ・試験版）

好きな人物・出来事・年代・場所を手がかりに、日本の歴史と関連する城跡・博物館を探せる、スマートフォン向けのWebアプリです。

試験版のテーマは「1590年 豊臣秀吉の小田原攻めと関東の城」です。東京都・神奈川県・埼玉県の8施設を収録しています。

## 使い方（3つの目的）

| 目的 | できること |
| --- | --- |
| 近くを探す | 現在地（許可した場合のみ）または地図の中心から、近い順に並べる |
| 人物・時代 | 人物・出来事・世紀を選ぶと、ゆかりの場所と記述を年代順に表示する |
| 旅先で | 都県を選ぶと、そこで訪ねられる場所と、つながりのある他県の場所を表示する |

施設の詳細画面では、記述ごとに「史実」「説」「伝承」の区別と出典を表示します。

## 技術構成

- Vite + TypeScript（静的サイト。サーバー・ログイン・データベースなし）
- 地図：Leaflet ＋ 地理院タイル（国土地理院）
- PWA：ホーム画面に追加でき、アプリ本体は電波が弱くても開ける
- 公開：GitHub Pages（GitHub Actions で自動ビルド）

## 開発

```bash
npm install
npm run dev          # 開発用サーバー
npm run check-data   # データの整合性チェック（出典の付け忘れなど）
npm run build        # 本番用ビルド（dist/）
```

## GitHub Pages での公開手順（初回のみ）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Build and deployment → Source** を **GitHub Actions** にする
3. `main` ブランチに push すると自動で公開される
   公開URL：`https://yf1900.github.io/historyconnect/`

## データ登録のルール

データは `src/data.ts` にあります。

- 記述は出典に書かれている範囲にとどめ、推測で補わない
- `type` で「史実（fact）」「説（theory）」「伝承（legend）」を区別する
- 開館時間・料金などの変動情報は、出典の掲載日・確認日を残す
- 座標は、公式情報で確認した住所を国土地理院の住所検索で変換して登録する。確認できない場合は `NaN` のままにする（地図には表示されず、一覧にのみ表示）
- 100名城の番号は日本城郭協会の公式番号を使う

## プライバシーとセキュリティ

- 位置情報は端末内で距離を計算するためだけに使い、送信・保存しない
- 端末に保存するのは「行きたい」に登録した施設IDのみ（localStorage）。アプリ内から消去できる
- Cookie・アクセス解析・広告は使わない
- Content-Security-Policy で読み込み先を自サイトと地理院タイルに限定し、リファラーを送らない
- 外部送信（地理院タイル・GitHub Pages）はアプリ内のプライバシーポリシーで公表

公開前に、プライバシーポリシーの「運営者名・連絡先」を記入してください（`src/main.ts` の `renderAbout`）。
